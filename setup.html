Thu thập câu trả lời của học sinh

Học liệu này gửi câu trả lời của học sinh tới một Google Sheet qua Google Apps Script. Việc cài đặt mất khoảng 5 phút và hoàn toàn miễn phí.

Bước 1 · Tạo Google Sheet

  1. Mở sheets.new để tạo một Sheet mới.
  2. Đặt tên: ví dụ Monty Hall — Lớp 11A.
  3. Thêm hàng tiêu đề cột đầu tiên (gợi ý): 
    timestamp | name | classroom | q1_answer | q1_correct | q2_answer | games_played | swap_wins | swap_total | stay_wins | stay_total

Bước 2 · Tạo Apps Script

  1. Trong Sheet, vào menu Extensions → Apps Script.
  2. Xoá toàn bộ code mẫu và dán đoạn sau:
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp,
    data.name,
    data.classroom,
    data.q1_answer,
    data.q1_correct,
    data.q2_answer,
    data.games_played,
    data.swap_wins,
    data.swap_total,
    data.stay_wins,
    data.stay_total
  ]);
  return ContentService
    .createTextOutput(JSON.stringify({ status: 'ok' }))
    .setMimeType(ContentService.MimeType.JSON);
}

Bước 3 · Triển khai Web App

  1. Bấm nút Deploy → New deployment.
  2. Chọn loại: Web app.
  3. Cấu hình:
    • Execute as: Me (tài khoản của bạn)
    • Who has access: Anyone
  4. Bấm Deploy, cấp quyền cho ứng dụng nếu được yêu cầu.
  5. Sao chép Web app URL (dạng https://script.google.com/macros/s/.../exec).

Bước 4 · Gắn URL vào bài học

  1. Mở bài học.
  2. Bật bảng Tweaks ở góc dưới-phải.
  3. Dán URL vào ô Google Sheet URL.
  4. Hoàn tất! Câu trả lời của học sinh sẽ tự động ghi vào Sheet.

Lưu ý kỹ thuật. Vì Apps Script không trả về CORS headers, bài học gửi request ở chế độ no-cors — nghĩa là trình duyệt sẽ ghi nhận thành công ngay cả khi server lỗi. Hãy mở Sheet để kiểm tra dữ liệu thực tế đã ghi chưa.

Phương án thay thế: Firebase

Nếu bạn muốn dùng Firebase Firestore, hãy mở file questions.jsx và thay hàm submitToSheet() bằng đoạn gọi addDoc(collection(db, 'monty-hall'), payload). Bạn cần thêm SDK Firebase vào index.html và khởi tạo app với cấu hình của project mình.
